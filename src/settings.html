Appearance:

Follow the system setting, or keep one appearance whatever the system does.

Read access to Issues and Pull requests. Stored encrypted on this Mac.

Results:

Uploads the PNG to the loupe-artifacts branch and keeps one comment per commit up to date. Needs Contents and Pull requests write access.

Devices:

Each device captures one command at a time; the queue spreads across all of them. One identifier per row, from xcrun simctl list devices or adb devices. A capture runs only on a device of its own platform.

Loopback addresses only, so capture never leaves this Mac.

One manifest per commit, so a screenshot always matches the code it came from.

Missing Build:

Needs Xcode and xcodegen. The first run on a commit takes a few minutes; later runs reuse it.
